# 📸 Gallery View

**Gallery View** is a Frappe app that enables a dynamic, clean, and responsive gallery display for any Doctype containing the field `custom_gallery_view` (of type **HTML**).

It automatically showcases all attached image files in a grid layout:

- 🖥️ **Desktop:** 4 images per row  
- 📱 **Mobile:** 1 image per row (responsive view)

Images are center-focused and fill the square layout for aesthetic consistency. Clicking an image opens it in a new tab at full size.

---

## ⚙️ How It Works

1. Add a field named `custom_gallery_view` (Fieldtype: HTML) to your Doctype.
2. Configure the Doctype inside the **Gallery View Settings** table.
3. All image attachments (e.g., `.jpg`, `.png`, `.webp`) for that document will be rendered as a responsive gallery.
